## Session 1 — Key Terms

### 1. Confidentiality
Confidentiality means keeping data private and protected from unauthorized people. Only people who have permission should be able to see the information.

### 2. Integrity
Integrity means keeping data correct and unchanged. No unauthorized person should be able to modify or delete the data.

### 3. Availability
Availability means that data and systems should be accessible when needed. For example, a website should be available to authorized users when they need it.

### 4. Threat
A threat is anything that can harm a computer system or data. Examples include hackers, malware, viruses, and fire.

### 5. Vulnerability
A vulnerability is a weakness in a system that an attacker can use. For example, outdated software or a weak password can be a vulnerability.

### 6. Risk
Risk is the possibility of something bad happening because of a threat exploiting a vulnerability. For example, an outdated server may be attacked and cause data loss.

### 7. Preventive Control
Preventive controls are used to stop security problems before they happen. Examples include firewalls, strong passwords, antivirus software, and locks.

### 8. Detective Control
Detective controls are used to find or detect security problems. Examples include security logs, IDS, monitoring systems, and alerts.

### 9. Corrective Control
Corrective controls are used to fix a problem after it happens. Examples include restoring backups, removing malware, and applying security patches.

### 10. ISO 27001
ISO 27001 is an international standard for information security. It helps organizations create an ISMS to protect their information and manage security risks.

### 11. DPDP Act 2023
The DPDP Act 2023 is an Indian law for protecting digital personal data. It provides rules for organizations on how personal data should be collected and processed.
